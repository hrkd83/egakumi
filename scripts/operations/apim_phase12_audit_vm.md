# 工程1・2の監査ログを管理VMから取得する

対象のWorkspaceに作業時の読み取り権限を付与し、保守担当者本人が管理VMから `workspace-query` を実行します。[管理VMから保守データを取得する](../../docs/operations.md#管理vmから保守データを取得する)

1. 対象のCore配備、要件の要求IDと実施時刻を保護記録で照合します。
2. [監査照合のクエリー生成](apim_phase12_audit_checks.md)で用意したKQLを、本人所有の保護ファイルへ保存します。クエリーごとに新しい保護出力先を使います。
3. 結果の列と行、欠測と部分エラーを確認し、監査照合処理へ渡します。ログの到着待ちや0件は、受入成功から分けて記録します。
4. 終了後は作業用のWorkspace読み取り権限を回収します。旧Run Commandの証跡は元の試行に紐付けて保護します。

監査本文、識別子、KQL、保護パスは公開記録へ転記しません。
