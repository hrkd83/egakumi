# HTTP本文監査

有限のHTTP操作で、共通認証と入力上限の確認後に元の入力を保持します。転送前に監査中継へ送り、Event Hubsの受領を待ちます。操作の応答加工後に同じ記録へ応答を追加し、受領を待ってからクライアントへ返します。下流の接続先、認証、ルーティングは操作ポリシーで管理します。

中継先にはAPIMのマネージドIDで接続します。本文はAPIMの文字列としてBase64で渡し、中継で元のバイト列に戻します。ヘッダーは相関・形式・状態の固定項目だけを渡します。サイズやストリーミングにより取得できない場合は、理由を証跡に残します。証跡保存前の資格情報除外と復元は[本文監査の仕様](../../../../../../docs/reference/audit/request-body-audit.md)を参照してください。
