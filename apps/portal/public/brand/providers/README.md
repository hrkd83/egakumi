# 提供元ロゴの出典

APIを提供する会社を識別するためのロゴです。サービスの推奨・提携・公認を意味しません。
提供元の素材を元の色・形・縦横比のまま表示し、アルファベットや汎用線画による代用品を混在させません。
取得日: 2026-10-31。素材自体は加工していません。

表示枠は56pxで統一しています。素材に含まれる余白量は各社で異なるため、画像全体の表示寸法は提供元ごとに調整し、実際の図柄が約28〜32pxで見えるようにしています。切り抜き、縦横比の変更、再着色は行いません。OpenAIのSVGは図柄の周囲に大きい透明余白を持つため、画像要素を64pxで中央に配置しても図柄は枠の内側に収まります。
