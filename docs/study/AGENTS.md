# 勉強会資料・動画の制作

動画制作を依頼されたら、まず `CONTENT-PLAN.md` の「新規セッションでの制作」を読み、そこから `video-sample/PRODUCTION-GUIDE.md` と `video-sample/production-profile.json` を参照する。

- ユーザーが指定したコンテンツ番号の到達点と対応資料から制作する。第1回を複製して題名だけ変えない。
- 現行音声は Gemini 3.8 Flash TTS、MAKO=Aoede / MANABU=Charon / IKUMI=Orus、全員通常速度。旧DragonHDの試作は現行指定ではない。
- 本編は採用済みの`teaching-settings-v2`に統一する。`video-sample/SETTINGS-VIEW.md`を読み、教材用の設定メニューと補助図を使う。Azureのブランドバー・検索欄などを部分的に模倣しない。
- 本編カメラは固定し、自動ズーム・パン・赤枠のpulseを入れない。質問から回答まで同じ`viewId`・構図・縮尺を保ち、台詞・話者・字幕chunkの切替で画面をリセットしない。赤枠は説明する対象に合わせ、確認問題の答えを先取りしない。
- 静止画だけでなく、40〜70秒程度の連続した質問・回答を動画で確認する。図や枠に言及する台詞には該当する図を置く。詳細と全体図を何度も往復させず、必要な補助図を同じ画面へ併記する。
- 並列タスクでは担当回の `video-sample/episodes/<key>/` と `video-sample/output/lesson-<key>-gemini/` のみ変更する。計画、共通仕様、キャスト、素材、レンダラーなどの共有ファイルを回ごとに変更しない。
- 完成状態・再生先・検証結果は担当回の `production.md` に書く。共有の計画表やREADMEを複数タスクから更新しない。
- ユーザーの明示的な追加指定があれば、その指定を優先する。

資料だけの修正では、依頼された範囲を通常どおり編集する。動画の実行ロックや出力先の規則を、資料の軽微な文章修正へ広げない。
