# 第10回 原音の独立信号監査

2026-11-02 JST。原音90件とgeneration.jsonを読み取り、原音・台本・生成記録を変更せずに監査した。詳細は`audio-audit.json`。

## 確認結果

- 全90件が24kHz / mono / PCM16。全件に非ゼロの音声があり、WAVのSHA-256と実尺は生成記録に一致。
- 原音合計934.00秒。台詞ごとは4.84〜16.52秒、中央値10.14秒。読み上げ文字数/秒は4.65〜7.95で、顕著な長短の外れ値なし。
- -55dBFS未満の10ms窓をquietとして調べ、最長連続quietは約1.03秒、先頭最大約0.32秒、末尾最大約0.48秒。全無音・長い無音の顕著な兆候なし。
- RMSは-20.23〜-15.01dBFS。原音peakは一部フルスケールに達しており、短い飽和の注意を残す。

## 原音ピークの注意

| 項目 | 結果 |
| --- | --- |
| near-full-scale定義 | 絶対PCM値32760以上 |
| 該当原音 | 45 / 90件 |
| 該当sample | 1064 / 22,416,000（約0.00475%） |
| 厳密なfull-scale sample | 1063 |
| 同極性near-full-scaleの最長連続 | 10sample、約0.417ms |
| 最多の台詞 | lesson10-turn-003-ikumi、261sample（当該原音の約0.128%） |

数値上の短い飽和runが原音にある。無音・欠音・異常尺とは別の注意として扱い、可聴な歪みを確認したとは断定しない。原音は採用仕様どおり保持した。JSONの`signalAuditPass=false`は、全near-full-scale sampleを検出する感度の高いスクリーニングが反応した意味であり、聴感の不合格や再生成の必要性を示すものではない。

## 確認していない範囲

発音、読み落とし、意味内容、話し方の自然さ、飽和の聴感はこの信号監査では確認していない。音声聴取・ASRは実施していない。完成MP4のミックス音量・True Peak・デコード検査は合成後の別工程で確認する。
