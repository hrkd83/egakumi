# 構築後の変更手順

[共通確認](common.md) · [運用テスト12項目](../testing/operations-tests.md)

運用中によく行う3つの変更を扱う。まず共通確認で対象環境・変更前の値・戻し方を確認し、対象の手順へ進む。

| 変更したいもの | 手順 | 使う入口 |
| --- | --- | --- |
| Portalの画面・文言・ガイド | [Portalを修正する](portal.md) | ローカル検査→Portal個別配備（P） |
| APIMのAPI定義・ポリシー | [API定義・ポリシーを修正する](apim.md) | 定義・ポリシーの検査→Gateway個別配備（G） |
| Foundryのモデル・配備容量 | [Foundryモデルを変更する](foundry.md) | Foundry GUI→設定を実物へ合わせる→必要なG／P |

初期構築は[構築手順](../setup/06-deploy.md)、環境の利用終了・撤去は[撤去手順](../operations.md#撤去する)を使う。通常の更新で基盤を作り直さない。

各手順は実装・ローカル回帰との机上確認を行う。運用テストの実環境への反映と判定は別工程であり、実施前の結果欄は未実施として扱う。
