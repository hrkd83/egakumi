# 実行記録の公開用テンプレート

元の組織環境の実行記録は公開用コピーから除外しました。このファイルには実環境の名前・識別子・担当者・判定・運用状況・残件を含めていません。過去の内部リンクを保つために案内だけを残しています。

自身の試行では [動作テスト仕様](../../../INTEGRATION_TESTS.md) と [構築テスト仕様](../../../CONSTRUCTION_TESTS.md) に従い、対象revision・環境・実施日時・前提条件・確認内容・期待結果・判定・残件・切戻し条件を保護した記録へ保存してください。秘密、認証URL、Cookie、キー、利用者の実データは公開文書へ転記しません。
